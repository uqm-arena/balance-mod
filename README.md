This is a fork of [the Ur-Quan Masters](https://sc2.sourceforge.net/) with the balance mod built-in. 

# Installation

## Windows

* On the [releases page](https://github.com/uqm-arena/balance-mod/releases), download the Windows exe zip and extract it into UQM's main directory. The default install location is `C:\Program Files (x86)\The Ur-Quan Masters` on modern Windows systems.

* On the [releases page](https://github.com/uqm-arena/balance-mod/releases), download the latest effects package and place it in `UQM\content\addons`. Do not extract this zip file. Any older versions of this zip file should be replaced or deleted before playing.

* Run `uqm-balance-mod.exe` to play.

## Mac

We are looking for someone to build the Balance Mod on OS X. Please submit your build via a pull request in the [Balance Mod Github repository](https://github.com/uqm-arena/balance-mod/pulls).

## Everything else

Download the source code for the [latest release](https://github.com/uqm-arena/balance-mod/releases). The effects add-on package is included in the source code package. Compiling the game on Linux and Linux-like systems should be identical to compiling the original UQM code: Install the required dependencies and run `./build.sh uqm`
